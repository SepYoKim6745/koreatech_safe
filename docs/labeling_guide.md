# AI 학습용 데이터 라벨링 가이드 (이미지 분석)

본 가이드는 AI에게 **"안전 위험 요소를 찾아내는 법"**을 가르치기 위한 데이터를 만드는 방법을 설명합니다.

## 1. 준비물
- **엑셀(Excel) 또는 구글 스프레드시트**
- 분석할 **이미지 파일들** (폴더에 모아두세요)

## 2. 작업 방법 (엑셀 작성)
엑셀에 아래와 같이 3개의 열(Column)을 만들고 내용을 작성해주세요.

| A열: 이미지 파일명 | B열: 질문 (User) | C열: 정답 (Assistant) |
| :--- | :--- | :--- |
| `site_A_001.jpg` | 이 사진의 위험 요소를 찾아줘. | 작업자가 안전모를 착용하지 않았습니다. |
| `site_A_002.jpg` | 작업장 상태가 안전한가? | 아니요. 바닥에 전선이 어지럽게 널려 있어 전도(걸려 넘어짐) 위험이 있습니다. |
| `site_B_005.jpg` | 이 상황의 문제점과 해결책은? | **문제점:** 사다리를 혼자 작업하고 있습니다. <br>**해결책:** 반드시 2인 1조로 작업하여 한 명은 사다리를 지지해야 합니다. |

### ⚠️ 작성 시 주의사항 (매우 중요)
1. **파일명 정확하게:** 이미지 파일의 이름(확장자 .jpg, .png 포함)이 엑셀의 A열과 **토시 하나 틀리지 않고 똑같아야** 합니다.
2. **구체적인 묘사:**
   - (나쁜 예): "위험하다."
   - (좋은 예): "**작업자가 2m 이상 높이의 비계에서 작업 중이나, 안전난간이 설치되지 않아** 추락 위험이 있습니다."
3. **전문 용어 사용:** 가능하다면 '모자' 대신 **'안전모'**, '줄' 대신 **'생명줄/안전대'** 등의 정확한 명칭을 써주세요.
4. **질문의 다양화:** B열의 질문은 "위험 요소는?", "안전한가?", "무엇이 문제인가?" 등으로 조금씩 다르게 적어주시면 더 좋습니다.

## 3. 작업 결과물 제출
- 작업이 완료된 **엑셀 파일**과 **이미지 폴더**를 함께 압축해서 전달해주세요.
