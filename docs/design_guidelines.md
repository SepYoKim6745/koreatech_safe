# 🎨 UI/UX 디자인 가이드라인

이 프로젝트는 **Apple 스타일의 미니멀하고 직관적인 디자인**을 지향합니다.

---

## 1. 브랜드 컬러 (Brand Colors)
| 색상명 | 변수명 | Hex | 사용처 |
| :--- | :--- | :--- | :--- |
| **Orange** | `--color-orange` | `#FF7F00` | 전송 버튼, 강조 포인트 |
| **Blue** | `--color-blue` | `#183072` | 사용자 말풍선, 헤더 포인트 |
| **Light Gray** | `--bg-sidebar` | `#F5F5F7` | 사이드바 배경, 입력창 배경 |

## 2. 레이아웃 가이드
- **메시지 버블**: 사용자는 우측 정렬(파란색), AI는 좌측 정렬(투명 배경)을 사용합니다.
- **통합 응답 UI**: '생각 중' 표시와 답변 텍스트를 하나의 영역에 배치하여 시각적 연속성을 유지합니다.
- **반응형**: 모바일 환경에서는 사이드바가 자동으로 숨겨지며 로고 클릭으로 제어합니다.

## 3. 타이포그래피
- **Font**: San-serif 계열 (Pretendard, Apple SD Gothic Neo 권장)
- **Content**: AI 답변은 완전한 검정색(`#000000`)과 `1.7`의 행간을 사용하여 가독성을 극대화합니다.

## 4. 컴포넌트 원칙
- 모든 모달은 `backdrop-filter: blur(4px)`를 사용하여 깊이감을 줍니다.
- 버튼 호버 시에는 부드러운 스케일 변화(`scale: 1.05`) 또는 색상 변화를 적용합니다.
