## [2026-02-09] v1.1 모델 추론 안정화 및 앵무새 현상 해결

LLM 답변 생성 중 동일한 문장을 반복하거나 대화가 비정상적으로 종료되지 않는 '앵무새 현상'을 해결하기 위해 추론 파라미터를 최적화했습니다.

### 1. 추론 파라미터 조정 (Stability Tuning)
*   **Temperature 최적화:** 답변의 일관성과 창의성 균형을 맞추기 위해 `temperature` 설정을 적용했습니다.
*   **Repetition Penalty 적용:** 동일한 토큰이나 문구가 반복되는 것을 방지하기 위해 `repetition_penalty` 파라미터를 추가하여 답변의 다양성을 확보했습니다.
*   **Top-P Sampling 도입:** 누적 확률 기반의 샘플링(`top_p`)을 통해 보다 자연스러운 단어 선택이 이루어지도록 개선했습니다.

### 2. 생성 종료 조건 최적화 (EOS Token Handling)
*   **종료 토큰 명시:** 모델이 답변을 마쳐야 할 시점을 정확히 인식할 수 있도록 `stop` 시퀀스(`<|im_end|>`, `<|endoftext|>`)를 명시적으로 추가했습니다.
*   **Stop Token IDs 지정:** vLLM 엔진 수준에서 종료 토큰 ID를 직접 전달하여 불필요한 추가 생성을 방지하고 리소스를 절약했습니다.

### 3. 답변 품질 개선
*   **루프 방지:** 반복 패널티 적용을 통해 특정 문구에 갇히는 현상을 제거했습니다.
*   **전문성 유지:** 기존 시스템 프롬프트와 결합하여 산업 안전 전문가로서의 어조를 유지하면서도 매끄러운 한국어 답변을 제공합니다.
