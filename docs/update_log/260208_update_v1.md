# 📋 시스템 업데이트 및 최적화 기록 (Update Log)

이 문서는 VLM Chatbot 시스템의 주요 변경 사항, 성능 개선 및 버그 수정 내역을 기록합니다.

## [2026-02-08] v1.0 통합 업데이트: 성능 최적화 및 보안 강화

오늘 발생한 서비스 병목 현상, 프리징 문제 및 답변 오류를 해결하고, 대규모 자원 활용을 위한 최적화와 보안 기능을 추가했습니다.

### 1. 성능 및 동시성 개선 (병목 현상 해결)
*   **비동기 추론 도입:** 백엔드 VLM 서비스를 동기 방식에서 비동기(`AsyncOpenAI`) 방식으로 전환하여 멀티 유저 대응력을 확보했습니다.
*   **DB 세션 관리 최적화:** AI 추론 중 DB 연결을 즉시 반납하도록 구조를 개선하여 UI 반응성을 즉각적으로 확보했습니다.
*   **SQLite WAL 모드 활성화:** 데이터베이스 동시성 향상을 위해 WAL(Write-Ahead Logging) 모드를 적용했습니다.
*   **GPU 자원 극대화:** 듀얼 RTX 5000 Ada(64GB VRAM) 환경에 맞춰 vLLM 문맥 길이를 **64,536(64k)**으로 4배 확장했습니다.

### 2. 보안 및 데이터 무결성 강화
*   **계정 탈퇴 기능 구현:** 백엔드와 프론트엔드에 계정 삭제 기능을 추가하고, 탈퇴 시 모든 대화 기록이 안전하게 제거되도록 구현했습니다.
*   **참조 무결성 보장:** SQLite `PRAGMA foreign_keys=ON` 설정을 통해 사용자 삭제 시 관련 데이터가 연쇄 삭제(`CASCADE`)되도록 강화했습니다.
*   **고아 데이터 정화:** 서버 시작 시 주인 없는 채팅방 및 메시지를 자동 청소하는 로직을 추가했습니다.

### 3. 사용자 경험(UX) 및 UI 디자인 고도화
*   **Apple 스타일 디자인 적용:** 모든 모달(확인 창)에 강력한 블러 효과(`backdrop-filter`)와 정교한 애니메이션을 적용하여 프리미엄 룩앤필을 구현했습니다.
*   **렌더링 최적화:** 답변 스트리밍 시 화면 갱신 빈도를 **100ms**로 제한하여 브라우저 부하를 방지했습니다.
*   **첫 메시지 버그 수정:** 새 채팅방 생성 시 스트리밍이 중단되던 `sessionId` 전환 로직을 수정했습니다.
*   **마크다운 렌더링 개선:** `remark-breaks`와 `rehype-raw`를 도입하여 HTML 태그(`<br>`) 처리와 마크다운 표(Table) 가독성을 확보했습니다.

### 4. 모델 지침 및 한계 대응
*   **시스템 프롬프트 주입:** AI가 반드시 한국어로만 답변하고 산업 안전 전문가로서 행동하도록 강제하는 시스템 프롬프트를 적용했습니다.
*   **대규모 문서 분석 확장:** 늘어난 토큰 한도에 맞춰 PDF 추출 제한을 **40,000자**로, 대화 기억을 **최근 30개**로 대폭 확장했습니다.
